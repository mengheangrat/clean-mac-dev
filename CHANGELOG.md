# Changelog

## 1.0.0

First open-source release.

- Disk overview with usage ring and free space.
- Cleans Xcode, simulator, npm, Gradle, Maven, CocoaPods, app caches and logs.
- Pick lists for iOS simulators, iOS runtimes, Android emulators and Android system images.
- Docker, Homebrew and pnpm cleanups; empty the Trash.
- Review screen before cleaning, live progress, and a result screen.
- Universal build (Apple Silicon and Intel), `.dmg` and `.pkg` installers.
- Terminal version in `scripts/clean-mac-dev.command`.
